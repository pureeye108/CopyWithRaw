How Automated File Pairing Works

When you select photos in your file manager or photo viewer, CopyWithRAW scans the directory in real-time to locate related assets.

  • ✓

    Prefix & Base Name Matching

    Matches edited or exported JPEGs back to original RAW captures even if suffixes were added during export.

  • ✓

    Broad Format Compatibility

    Supports .NEF, .CR2, .CR3, .ARW, .DNG, .RAF, .ORF, .RW2, .PEF, and more.

  • ✓

    Batch Coordination Engine

    Combines multi-selected files into a single background batch session, guaranteeing fast processing with zero duplicate popups.

FastStone Image Viewer Integration

Add CopyWithRAW to FastStone for blazingly fast photo culling with hotkeys.

  1. Open FastStone Image Viewer and press F12 to open Settings.
  2. Select the Programs tab at the top and click Add.
  3. Enter a name such as Copy to WL (Auto).
  4. Browse to the executable script inside your install directory:
    C:\Program Files\CopyWithRAW\RunHidden.vbs
  5. In the parameter box, add the destination argument:
    "%src%" "WL:" "AutoSubfolder"
  6. Click OK. Now press Alt + 1 or E anytime in FastStone to trigger the copy!
