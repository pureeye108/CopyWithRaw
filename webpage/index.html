How It Works

You don't need to manually search for matching .NEF, .CR3, or .ARW files in your photo folder. Select the JPEG (or the RAW), right-click Copy with RAW, and the rest get copied over automatically — including .xmp edit files!

⚡ Portable Scripts Package — What it is & How to Use

The Portable Scripts package contains the raw batch files (Install.bat, CopyWithRAW.ps1, RunHidden.vbs, and FastStone helpers) for users who want to run the scripts directly without an installer wizard.

  1. Download and extract CopyWithRAW-Windows-Portable-Scripts.zip to a permanent folder on your computer (e.g. C:\CopyWithRAW\).
  2. Inside the folder, right-click Install.bat and select "Run as administrator".
  3. That's it! Right-clicking any JPEG or RAW file in File Explorer will now display the Copy with RAW menu options.
💡 Windows SmartScreen Notice: If Windows shows "Windows protected your PC" when launching the installer, simply click "More info" and then click "Run anyway".
