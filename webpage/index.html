Select JPEG or RAW.
Copy Both Automatically.

When backing up photo folders, select just one file. CopyWithRAW automatically finds and copies both the JPEG and RAW photo files together.

How It Works

You don't need to manually search for matching .NEF, .CR3, or .ARW files in your photo folder. Select the JPEG (or the RAW), right-click Copy, and the rest get copied over automatically — including .xmp edit files!
